YouTube KPI 自動更新

YouTube チャンネルの数字（再生数・総再生時間・推定収益・登録者の増減・動画ごとの成績など）を YouTube Data API と YouTube Analytics API で読み取り、共有の Google スプレッドシート（KPI シート）の、そのチャンネルのタブへ毎朝7時ごろに自動で書き込むツールです。

  • 登録は、登録ページでチャンネルを選んで許可するだけです。
  • 求める権限は YouTube の読み取りだけです。動画の投稿・削除・変更はできません。
  • やめるときは、Google アカウントの「サードパーティ製のアプリとサービス」でこのアプリの許可を削除してください。
