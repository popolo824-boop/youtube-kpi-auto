プライバシーポリシー（YouTube KPI 自動更新）

取得する情報

利用者が許可した YouTube チャンネルについて、チャンネル名・チャンネルID・登録者数・公開動画の一覧（タイトル・公開日・長さ）と、YouTube Analytics の集計値（再生数・総再生時間・推定収益・登録者の増減・視聴維持率）を読み取ります。権限は読み取り専用（youtube.readonly / yt-analytics.readonly / yt-analytics-monetary.readonly）です。

使い方

取得した数字は、利用者が参加している共有の KPI スプレッドシートの、そのチャンネル名のタブに書き込むためだけに使います。広告・販売・第三者への提供・AI の学習には使いません。

保存

毎朝の更新のため、許可で得た更新用トークン（リフレッシュトークン）とチャンネル名を、このツールの Google Apps Script のプロパティに保存します。数字そのものはスプレッドシートにだけ残ります。

共有

書き込んだ数字は、その KPI スプレッドシートを見られる人に見えます。それ以外には共有しません。

削除

Google アカウントの「セキュリティ」→「サードパーティ製のアプリとサービス」でこのアプリの許可を削除すると、以後は取得しません。保存したトークンの削除やシートの数字の削除を希望するときは、同意画面に表示されるサポート用メールアドレスへ連絡してください。

Google API サービスのユーザーデータに関するポリシー

このツールによる Google API から受け取った情報の使用は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。YouTube の利用には YouTube 利用規約 と Google プライバシーポリシー が適用されます。
